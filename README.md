# 🚖 OLA Ride Analytics Dashboard | Power BI

## 1. Project Title / Headline

**OLA Ride Analytics Dashboard – Interactive Ride Booking & Business Performance Analysis Using Power BI**

## 2. Short Description / Purpose

Developed an interactive five-page Power BI dashboard to analyze OLA ride-booking data and gain insights into business performance, ride trends, revenue, cancellations, and customer and driver ratings.

The dashboard transforms raw booking data into meaningful insights through interactive visualizations, KPIs, and data-driven analysis, helping understand ride operations and business performance.

## 3. Tech Stack

- **Microsoft Power BI** – Interactive dashboard development and data visualization.
- **DAX** – Calculated measures, KPIs, and business metrics.
- **Power Query** – Data cleaning and transformation.
- **CSV / Dataset** – Data storage and analysis.
- **Data Modeling** – Organizing data for meaningful analysis.

## 4. Data Source

The project uses an OLA ride-booking dataset containing information related to:

- Ride booking details.
- Vehicle types.
- Booking status.
- Revenue and payment methods.
- Customer and driver ratings.
- Ride cancellation information.

The dataset was processed and transformed using Power Query before dashboard development.

## 5. Features / Highlights

### 📊 1. Overall Dashboard
- Total Bookings and Total Booking Value.
- Ride Volume Over Time.
- Booking Status Breakdown.
- Date-based interactive filtering.

### 🚗 2. Vehicle Type Analysis
- Vehicle-type-wise ride analysis.
- Booking and performance KPIs.
- Comparative analysis across vehicle categories.

### 💰 3. Revenue Analysis
- Revenue by Payment Method.
- Top 5 Customers based on booking value.
- Revenue-related business insights.

### ❌ 4. Cancellation Analysis
- Cancelled Rides by Customers.
- Cancelled Rides by Drivers.
- Total Bookings and Succeeded Bookings.
- Cancelled Bookings and Cancellation Rate.

### ⭐ 5. Ratings Analysis
- Customer Ratings Analysis.
- Driver Ratings Analysis.
- Vehicle-type-wise rating insights.
- Interactive rating analysis.

### ⚡ Interactive Dashboard Highlights
- Five interactive report pages.
- Dynamic date slicers and filters.
- KPI cards, charts, and tables.
- DAX measures for business calculations.
- Interactive data visualization for better decision-making.
